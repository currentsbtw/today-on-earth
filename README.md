# Today On Earth

Today On Earth is a news heatmap with no editorial voice: a flat world map that glows where the world's press is writing about something, built from GDELT's free 15-minute Global Knowledge Graph feed. An ingest job (`ingest/`, Node 24 + TypeScript) keeps a rolling 24-hour window of geocoded articles, bins them into H3 resolution-3 cells, and writes static JSON files (`heat.json`, `cells/<id>.json`, `state.json.gz`) described in `docs/DATA-CONTRACT.md`; the static site (`web/`) reads only those files. To run the ingest locally: `cd ingest && npm install && npm run ingest` (writes to `ingest/out`; set `COLD_START_HOURS=1` for a quick first run, `OUT_DIR=../web/public/data` to feed the local site, and `npm test` / `npm run check` to run the unit tests and validate the output against the contract). To run the site: `cd web && npm install && npm run dev`. To deploy on GitHub: make the repository public (scheduled Actions minutes are free there), set Settings → Pages → Source to "GitHub Actions", and add a repository variable `SITE_URL` (Settings → Secrets and variables → Actions → Variables) holding the site's base URL, for example `https://<user>.github.io/today-on-earth`. The `Snapshot` workflow then runs every 15 minutes, reads the previous window from `$SITE_URL/data/state.json.gz`, and deploys the rebuilt site; until `SITE_URL` is set or the first deploy exists, each run cold-starts from the last 6 hours of GDELT files.

Note: GitHub disables scheduled workflows in public repositories after 60 days without repository activity. Push a commit or run the `Snapshot` workflow manually (Actions → Snapshot → Run workflow) at least every two months, or add a keep-alive step later, or the map stops updating.
